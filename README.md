# «АЯЗ» — лендинг центра УЗИ-диагностики

Демо-шаблон для портфолио. Ниша: ультразвуковая диагностика и чек-апы, Республика Татарстан.
Реализован по ТЗ из [description.md](description.md).

**Стек:** Astro 7 + Tailwind 4 + ванильный JS. Без фреймворков на клиенте.
**Демо:** https://manath-iq.github.io/clinic-template/

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статика в dist/
```

---

## Архитектура

Трёхслойная: ядро ниши отделено от данных клиента.

```
src/
  core/                    ← переиспользуемо между клиентами, не трогается
    components/            ← 18 компонентов лендинга
    layouts/               ← Base.astro (SEO, schema), Page.astro (служебные страницы)
    styles/                ← tokens.css (дизайн-система), fonts.css, global.css
  client/                  ← ВСЁ, что меняется под клиента
    content.json           ← тексты, услуги, цены, врачи, реквизиты, FAQ
    theme.css              ← переопределение токенов
  pages/                   ← index, price, privacy, license
    assets/fonts/          ← Onest, Golos Text, JetBrains Mono (woff2, идут в бандл)
    lib/url.ts             ← пути с учётом base
public/
  img/                     ← портреты врачей, интерьеры, hero-объект, макет лицензии
```

**Смена клиента:** правка `client/content.json` + подмена `public/img` + 2–3 переменные
в `client/theme.css`. Ядро не редактируется.

## Дизайн-система

Язык взят от самого метода: сектор сканирования, градации B-режима, допплеровское
картирование. Не «медицинский голубой со стетоскопом».

**Палитра** (`core/styles/tokens.css`):

| Токен | Значение | Роль |
|---|---|---|
| `--ink` | `#0B2430` | текст, тёмные острова |
| `--paper` | `#ECEFF0` | фон, 70% площади |
| `--pulse` | `#0D7A72` | CTA, ссылки, мелкий текст |
| `--pulse-bright` | `#12958C` | графика: скан, схемы |
| `--doppler` | `#E2563C` | крупные цены |
| `--doppler-text` | `#C2401F` | мелкий текст и метка «чаще выбирают» |

Бренд-тон из ТЗ (`#12958C`) даёт на `--paper` только 3.24:1 — ниже порога 4.5:1 из п. 12.
Поэтому тон разведён: затемнённый вариант для текста (4.6:1 и 5.2:1 на кнопке), исходный —
для графики, где контраст не нормируется.

**Типографика:** Onest (display) / Golos Text (body) / JetBrains Mono (все числа,
`tabular-nums`). Шрифты локальные, вариативные, сабсет кириллица + латиница — 146 КБ на три
семейства.

**Форма.** Скругления 10 / 18 / 26px и пилюли, мягкие тени вместо волосяных линий,
bento-сетка из плиток. Это осознанное расхождение с п. 8.4 ТЗ (там запрещены пилюли и тени):
заказчик выбрал язык присланных референсов — крупные фото-плитки с чипами поверх и круглыми
кнопками-стрелками. Примитивы `.tile` / `.pill` / `.arrow-btn` лежат в `tokens.css`.

**Signature:** сектор-скан в hero (`ScanSector.astro`) — SVG-геометрия + canvas-развёртка на
`requestAnimationFrame`. Один проход при загрузке, затем амбиентная пульсация с периодом 6 с.
Единственное, что движется бесконечно. Эхо мотива — волновой разделитель (`WaveDivider.astro`).

## Что реализовано

**Конверсия.** Подбор исследования с мгновенным поиском и фильтром по зонам; программы с
раскрывающимся составом и экономией; клик по услуге, программе, врачу или свободному слоту
прокидывает значение в форму записи.

**Юридический слой (ПП РФ № 736, ФЗ-38, 152-ФЗ).** Цены в рублях без «от» у каждой позиции;
квалификация каждого врача; лицензия с перечнем видов работ + скан в лайтбоксе; реквизиты
юрлица; ссылки на клинрекомендации Минздрава и pravo.gov.ru; предупреждение о
противопоказаниях; дисклеймер об оферте; сроки ожидания и порядок претензий; отдельная
страница политики ПДн; чекбокс согласия не отмечен по умолчанию и блокирует отправку;
cookie-баннер с отказом от аналитики. Формы не собирают сведения о здоровье.

**Доступность.** Версия для слабовидящих (класс на `<html>`, кегль 20px, ч/б контраст,
изображения off, состояние в localStorage); focus trap и Esc в модалке; табы прайса с
клавиатуры; видимый фокус; `prefers-reduced-motion` глушит всю анимацию.

**Мобильная версия.** Проектировалась первой: плитки зон в одну колонку с крупными тач-зонами,
hero — вертикальный стек «заголовок → плитка с объектом → слоты → быстрые услуги», карточки
врачей на всю ширину. Sticky-панель «Позвонить / Записаться / WhatsApp» после 400px, не
перекрывает футер; телефон в шапке всегда виден; фильтры горизонтальным скроллом; прайс
перестраивается из таблицы в компактные строки; статичная карта с кнопкой перехода.

## Что нужно доделать перед боевым запуском

1. **Отправка форм.** Сейчас демо-режим: успех показывается без запроса. Нужен серверный
   эндпоинт на хостинге в РФ (Timeweb / Reg.ru / Selectel) → Telegram-бот + почта, с
   валидацией телефона на сервере и rate limit. Honeypot-поле уже в разметке.
2. **Яндекс.Метрика.** Точка инициализации — в `CookieBanner.astro`, вызывается при согласии
   `all`. Цели уже размечены атрибутами `data-goal`: `phone_click`, `whatsapp_click`,
   `price_open`, `program_open`, `slot_click`.
3. **Изображения.** Портреты врачей, интерьеры и hero-объект сгенерированы нейросетью — лица
   вымышленные, это осознанное решение для демо (п. 7 ТЗ). Для боевого проекта нужны фото
   реальных врачей клиники с их письменного согласия.
4. **Юридическая сверка.** ПП РФ № 736 действует до 01.09.2026 — перед запуском сверить
   перечень обязательных сведений с новой редакцией. Политику ПДн согласовать с юристом.
5. **Реальные данные.** Реквизиты, лицензия, врачи, отзывы и цены в `content.json` —
   вымышленные. Отзывы лучше заменить виджетом агрегатора (ПроДокторов / Яндекс).

## Деплой

Публикуется на GitHub Pages при пуше в `main` — workflow `.github/workflows/deploy.yml`
собирает Astro и выкладывает `dist/`.

Так как Pages отдаёт сайт из подпапки репозитория, в `astro.config.mjs` задан
`base: '/clinic-template'`. Все ссылки на статику и страницы строятся через хелпер
`src/core/lib/url.ts`, шрифты подключены как модули из `src/core/assets/fonts` —
поэтому смена `base` не ломает пути.

**Перенос на боевой домен:** в `astro.config.mjs` убрать `base` и заменить `site`
на домен клиники. Больше ничего править не нужно.

Исходники генерации изображений (PNG по 1.5–2 МБ) лежат в `.assets-source/` и
не попадают в репозиторий — в сборку идут только сжатые WebP/JPEG из `public/img`.
